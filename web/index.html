Baseline Sources & Methodology

Security rules defined in CloudGuard AI are modeled with reference to established cloud security standards, including:

  • AWS Well-Architected Framework: Security Pillar controls for identity, data protection, and incident response.
  • CIS Amazon Web Services Foundations Benchmark: Industry standard security hardening guidelines.
  • NIST Cybersecurity Framework (CSF 2.0): Structural guidelines for asset protection and continuous monitoring.

Note: Rule evaluations are static checks performed against local configuration JSON templates and do not constitute formal compliance certification.
